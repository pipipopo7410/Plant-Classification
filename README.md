# 植物｜分類 — 正式版 v1.0.4

此版為教師已確認完成的植物①「分類」，網站與植物②「運輸與光合」、植物③「生殖與遺傳」分開部署。

## GitHub Pages 上架

1. 建立新的 GitHub 儲存庫，例如 `Plant-Classification`（已有儲存庫則使用現有儲存庫）。
2. **將 ZIP 解壓縮**，選取解壓後的**全部檔案**上傳到儲存庫根目錄。請確保 `index.html` 位於儲存庫最外層，而不是多包一層資料夾。不要只上傳 ZIP 檔案。
3. 開啟 GitHub 儲存庫 → **Settings → Pages**，設定 **Deploy from a branch**、分支 `main`、路徑 `/(root)`，按 Save。
4. 部署完成後，實際開啟網址測試，再到「剛剛數位小教室」入口網站把「植物 → 分類」按鈕連過來。

如果儲存庫名稱是 `Plant-Classification` 且 GitHub 帳號是 `pipipopo7410`，預期網址為：`https://pipipopo7410.github.io/Plant-Classification/`，但只有部署成功後才會生效。

## 本站內容與檢查

- 第一階段：植物分類架構建立、拖曳與連線、通關判定、範圍框的字卡推開互動。
- 第二階段：14 張真實植物圖片辨認；固定階層排列，配對後顯示植物名稱。
- 介面：與「植物｜運輸與光合」統一的柔和配色與一列式導覽列。
- 使用環境：橫向平板／電腦；PWA 安裝圖示與離線快取資源同包。

## 離線與更新注意事項

- GitHub Pages 的 HTTPS 網頁可註冊 Service Worker；直接在電腦開啟 `index.html` 可測試基本操作，但不能藉此驗證 PWA 快取。
- 初次連網載入後，等待資源快取完成，再以飛航模式重新開啟，才算通過裝置上的離線驗收。
- 若更新版本，務必同步更新 Service Worker 快取版本，避免裝置使用舊檔案。

此正式包直接沿用**v1.0.4 測試版既有的 20 個網站檔案**，未重寫教學程式或替換圖片；僅更換附帶的上架說明文件。原先的測試環境檢查與使用者實際操作驗收是不同層級；PWA 的 iPad 實機安裝／離線狀態仍需部署後確認。
